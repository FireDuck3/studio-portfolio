# Сайт-портфоліо вебстудії

Статичний сайт без збірки: можна викласти на будь-який хостинг (Netlify, Vercel, GitHub Pages, Cloudflare Pages).

## Структура
- `index.html` — головна: оффер, стрічка робіт, переваги, роботи й ніші, ціни, процес і гарантії, команда, FAQ, квіз-заявка, повноекранне меню.
- `cases/*.html` — окрема сторінка кожного кейсу (генерується, див. нижче).
- `demos/barber|coffee|dental/` — три робочі демосайти.
- `assets/styles.css`, `assets/main.js` — спільні стилі та скрипти.
- `assets/team/` — фото команди (WebP, 1000×800).
- `assets/shots/` — скріншоти демосайтів для карток (WebP, без демо-плашки). Після зміни демо зробіть нові скріншоти (1440×900 для комп'ютера, 390 px завширшки для телефона) з тими самими назвами.
- `sitemap.xml`, `robots.txt`.

## Що замінити перед запуском
1. **YOUR·STUDIO** → назва студії (пошук по всіх файлах).
2. `assets/main.js`: `CONTACT_EMAIL` і `FORM_ENDPOINT` (Formspree / Getform / свій обробник у Telegram). Поки `FORM_ENDPOINT` порожній, квіз відкриває пошту з готовим листом.
3. `index.html`: Telegram, email, ціни пакетів, реквізити ФОП у футері.
4. `tools/build-cases.mjs`: `SITE` (ваш домен), тексти кейсів.

## Кейси
Тексти кейсів лежать у `tools/build-cases.mjs`. Після змін:
```
node tools/build-cases.mjs
```
Буде перезаписано `cases/*.html` і `sitemap.xml`.

## Персональні посилання для продавця
- Кейс під нішу: `https://ваш-домен/cases/barber.html`
- Квіз із вибраним типом сайту: `https://ваш-домен/?type=services#contact` (`landing`, `services`, `shop`)

## Шрифти та фото
- Шрифти: Inter (сайт студії), Playfair Display / Lora / Manrope (демо) — з Google Fonts.
- Фото в демосайтах — з Unsplash (вільна ліцензія), підвантажуються за посиланням. Для реального клієнта замініть на його власні фото.

## Аналітика
Кнопки мають атрибут `data-track`. Підключіть GA4 (`gtag`) або Plausible — події (`demo_open`, `lead_submit`, `cta_*`) підуть туди автоматично.

## Після оновлення CSS/JS
Збільште `?v=9` (і `V` у `tools/build-cases.mjs`) у посиланнях на `styles.css` / `main.js`, щоб у відвідувачів не лишилась стара версія з кешу.
